# WeaveGen AI - Textile Dataset Directory & Licensing Guide

## 1. Directory Structure

```text
backend/datasets/
│
├── images/
│   ├── kanchipuram/
│   │   ├── kanchi_peacock_01.jpg
│   │   ├── kanchi_temple_02.jpg
│   │   └── ...
│   ├── pochampally/
│   │   ├── pocha_ikat_01.jpg
│   │   └── ...
│   ├── patola/
│   ├── baluchari/
│   ├── sambalpuri/
│   └── mangalagiri/
│
└── labels/
    └── dataset_metadata.json
```

## 2. Expected Image Specifications

- **Format:** RGB JPEG or PNG
- **Target Resolution:** $128 \times 128$ (for prototype / CPU training) or $256 \times 256$ (for GPU training)
- **Aspect Ratio:** 1:1 Square (ideal for repeating weave tiles)
- **Color Depth:** 8-bit per channel (24-bit RGB)

## 3. Dataset Licensing & Ethical Usage

When utilizing Indian handloom datasets for academic B.Tech research:

1. **Neural-Loom Dataset:** Check the academic publication license (typically CC-BY-NC 4.0 for non-commercial educational research).
2. **Museum & Open Access Archives:** The Metropolitan Museum of Art Open Access (CC0) and Victoria & Albert Museum provide high-resolution historic Indian handloom swatches.
3. **Artisan Attribution:** In accordance with ethical AI guidelines, document the geographic origin, community weave technique (e.g., Korvai, Single/Double Ikat, Bandha), and master artisan cluster.
4. **Honest Labeling:** All synthetic designs generated by the cGAN model must be clearly designated as AI-synthesized designs and not sold as handwoven originals.

## 4. Dataset Annotation Schema (`labels/dataset_metadata.json`)

Each entry must map filename to its condition attributes:
```json
{
  "image_path": "images/kanchipuram/kanchi_peacock_01.jpg",
  "region": "kanchipuram",
  "motif": "peacock",
  "symmetry": "bilateral",
  "density": "high",
  "dominant_colors": ["#8B0000", "#D4AF37", "#006400"]
}
```
